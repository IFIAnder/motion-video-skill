# 验收清单

分三层。**顺序不能换**：机器层不过，人眼看的是废片。
每一层都要真的做完，不许"看着差不多"。

---

## 第一层 · 机器验收（audit.mjs，必须有）

```bash
node scripts/audit.mjs --video out/v.mp4 --fps 30 --duration 3 --width 1920 --height 1080
```

| 检查项 | 通过标准 |
| --- | --- |
| verdict | `PASS`，或所有 `WARN` 都有书面解释 |
| 元数据 | 尺寸/帧率/时长与 storyboard 一致 |
| 是否在动 | 变化像素峰值 > 0.2%，局部灰度差峰值 > 35 |
| 中段静止 | 没有未标注的 ≥0.55s 静止段 |
| 硬跳变 | 没有未解释的跳变；有则说明是场景切换 |
| 平帧 | 没有整帧纯色（除非该段设计为纯背景） |
| 闪烁 | 没有"动了立刻静止"反复出现 |
| 循环接缝 | 循环动效必须 `--loop` 检查并干净 |

补充命令：

```bash
# 循环动图必须查接缝
node scripts/audit.mjs --video out/v.gif --loop

# 需要存档结论
node scripts/audit.mjs --video out/v.mp4 --json out/audit.json
```

## 第二层 · 人眼抽检（自己看图，不能省）

先用 `--still` 抽 3–5 个时刻，或直接看 `-sheet.png`。逐条过：

### 版面
- [ ] 文字没有溢出画面，四边留了 ≥80px 安全区（1920x1080）
- [ ] 视觉重心在预期位置（居中 / 三分法 / 元素群重心），没有"重心偏到角落"
- [ ] 元素之间没有意外重叠、没有元素被盖住
- [ ] 留白够：大面积背景不等于空，但也不该塞满

### 层级与对比
- [ ] 至少 3 个层级可辨（主标题 / 次文字 / 装饰）
- [ ] 暗底（#0b0e14 一类）上最暗的文字不低于 #6d8bbd；更暗要加字号或字重
- [ ] 强调色只用于 1–2 个地方，没有到处撒
- [ ] 文字与背景有对比，不是"灰字压在深灰底"上

### 时间感
- [ ] 入场 0.4–0.8s（更慢会腻，更快会看不清）
- [ ] 停留 ≥0.8s（观众要有时间读）
- [ ] 出场 0.3–0.5s（收得干脆）
- [ ] 元素之间有错开（stagger 40–120ms），没有所有东西同时动
- [ ] 没有元素在画面外就开始动、或在画面中央突然消失

### 收尾
- [ ] 末帧是设计好的定格状态（不是动到一半被截断）
- [ ] 循环动效的首末帧语义连贯（不只是像素相同，是**读起来**接得上）

## 第三层 · 交付物

- [ ] 成片：`out/v.mp4`（或 webm / gif，符合第 0 步定的格式）
- [ ] 接触表：`out/v-sheet.png`
- [ ] 规格：`storyboard.md`（含镜头表 + 元素时间轴表）
- [ ] 验收结论：audit 的 verdict 几行，或 `audit.json`
- [ ] 源码：`scene.html`（单文件，可复现）

交付说明里要写清三件事：

1. 产物是什么、多长、什么尺寸、什么格式
2. audit 的结果；有 WARN 的话，每条为什么可接受
3. 已知限制（哪些地方是妥协的，例如"元素数多，2x 超采样没开"）

---

## 自检的三个提问（交付前问自己）

1. **这个片子在第 1.5 秒在干什么？** 答不出来 → 中段是空的
2. **把声音关掉、缩放成 400px 宽，还看得出在讲什么吗？** 看不出 → 信息密度不对（除非是纯氛围片）
3. **如果用户只看第一帧和最后一帧，能理解意图吗？** 不能 → 首末帧没有承载信息

这三个问题比任何清单都便宜，也最能暴露问题。
